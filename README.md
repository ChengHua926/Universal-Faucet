# Universal Faucet CLI

This repo owns the miner client only:

```text
drip CLI
  -> local EVM identity
  -> bundled/managed XMRig
  -> external Stratum pool/backend
  -> local cumulative voucher cache
  -> claim/withdraw handoff UX
```

Out of scope here:

```text
backend
Stratum gate
XMRig Proxy
Postgres accounting
share validation
contracts
Crossroads routing/swap/bridge
relayer service
```

The backend/API is owned elsewhere. `drip` talks to it through:

```text
GET  /miner/:addr
GET  /pool
GET  /state/:addr
POST /voucher
POST /restore
```

`addr` is the local Ethereum address generated by the CLI. It is also the
XMRig username.

## User Install

Users do not clone this repo. Users receive a release archive that contains
`drip` and bundled XMRig.

```bash
mkdir -p ~/.local/opt ~/.local/bin
tar -xzf drip-darwin-arm64.tar.gz -C ~/.local/opt
ln -sf ~/.local/opt/drip-darwin-arm64/drip ~/.local/bin/drip
export PATH="$HOME/.local/bin:$PATH"
drip --help
```

If macOS blocks the unsigned binary:

```bash
xattr -dr com.apple.quarantine ~/.local/opt/drip-darwin-arm64
```

## User Commands

```bash
drip identity
drip start --threads 1
drip status
drip checkpoint
drip withdraw base-sepolia eth 0x1111111111111111111111111111111111111111
drip stop
```

For a clean demo profile:

```bash
export DRIP_HOME=/private/tmp/drip-demo
```

Logs:

```bash
tail -f /private/tmp/drip-demo/xmrig.log
```

Production defaults are built in:

```text
API  = https://p8080.m269.opf-mainnet-rofl-55.rofl.app
Pool = stratum+ssl://p3333.m269.opf-mainnet-rofl-55.rofl.app:443
```

No environment variables are required for normal use.

## XMRig

Users do not install XMRig. The release package bundles a source-built XMRig
binary.

The generated XMRig config uses:

```text
pool url = config.mining_pool_url
user     = local Ethereum address
pass     = x
rig-id   = local Ethereum address
sni      = true for rofl.app pool hosts
socks5   = config.tor_socks5, when set
cpu.rx   = one -1 affinity entry per requested thread
```

For the ROFL faucet pool, the production Stratum URL is
`stratum+ssl://p3333.m269.opf-mainnet-rofl-55.rofl.app:443`. `drip` enables
SNI in the generated XMRig config for `rofl.app` hosts. Relay and Tor endpoints
remain fallback paths.

Package XMRig:

```bash
DRIP_XMRIG_PLATFORM=darwin-arm64 scripts/package-xmrig.sh
```

Package `drip` with bundled XMRig:

```bash
DRIP_XMRIG_PLATFORM=darwin-arm64 scripts/package-xmrig.sh
DRIP_XMRIG_PLATFORM=darwin-arm64 scripts/package-drip.sh
```

## Voucher Model

While mining, `drip` runs a background checkpoint helper. Every configured
interval, default 300 seconds, it calls:

```http
POST /voucher
{ "user": "0x<addr>", "amount": null }
```

The response is cumulative. The CLI stores exactly one voucher: the highest
`cumulative_amount` seen.

Stored voucher shape:

```json
{
  "user": "0x...",
  "cumulative_amount": "12345",
  "signed_at": 1780000000,
  "signature": "0x..."
}
```

`drip restore` replays that voucher to `POST /restore`.
